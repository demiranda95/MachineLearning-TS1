# MachineLearning-TS1

# Predicción de Ventas Semanales

## Descripción
Este repositorio contiene el Trabajo Sumativo 1 de Machine Learning, cuyo objetivo es desarrollar un modelo predictivo capaz de estimar las ventas semanales en el contexto del retail, utilizando técnicas de análisis de datos y machine learning.

El caso de estudio corresponde a Walmart Sales Forecasting, donde se integran múltiples fuentes de datos, se realiza análisis exploratorio, tratamiento de datos y construcción de modelos predictivos orientados a apoyar la toma de decisiones.

---

## Modelos utilizados
- Regresión Lineal
- Random Forest

---

## Evaluación de modelos

Se utilizaron las siguientes métricas:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)

### Resultados obtenidos:

| Modelo             | MAE   | RMSE  |
|--------------------|-------|-------|
| Regresión Lineal   | 14,704 | 21,036 |
| Random Forest      | 1,654  | 3,493  |

El modelo Random Forest presentó el mejor desempeño.
